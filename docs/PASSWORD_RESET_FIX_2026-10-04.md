# 重置密码流程修复与验证（2026-10-04）

## 根因及修复范围

线上前端的合法密码可以通过正则；“请与所请求的格式保持一致”主要来自浏览器原生
`pattern` 校验，用户无法知道违反了哪条规则。原流程还会保留旧身份的发码提示、
验证码和敏感输入，迟到响应可能更新已关闭或已换身份的表单。

本次从上游 `2fda219c3ad44a476815820a7ebf1725fa13d374` 建立独立修复。
不修改后端接口、密码政策或数据库，不混入审计分支其他整改。

- 用户名明确为注册用户名，不能填邮箱或昵称；3–50 位英文字母、数字、下划线。
- 新密码明确为 8–16 位 A–Z/a–z/0–9，至少一个字母和数字。禁止空格、符号、全角；
  不自动改写密码、不截断超过上限的输入。
- 表单使用 `novalidate` 和显式校验，按长度、字符、组合、确认密码分别说明错误。
  发码只校验身份字段；提交校验全部字段，聚焦首个错误，并提供关联的无障碍说明。
- 发码绑定身份快照、请求代次和截止时间。改身份清除旧验证码与提示，关闭/卸载取消
  客户端等待；迟到的成功、失败和 finally 都不能污染当前表单。
- 发码、改密互斥，改密冻结提交快照并锁定编辑。关闭和成功清除密码及验证码。
  超时或取消不声称服务器撤销；提示先尝试新密码登录，不自动重发写请求。
- 共享认证页补上回填用户名、清空登录密码和成功提示；保留旧登录页的同等行为。

## 验证方法及证据

所有编译、浏览器和真实业务验证均在小主机完成，使用本轮独立回环测试服务。
没有向现有部署发送注册邮件或改密写请求。步骤及运行入口见
[测试说明](../web/tests/password-reset/README.md)。

| 验证 | 结果 |
|---|---|
| 后端 Java 21 / Maven package | 通过；后端未改，未声称执行全部单测 |
| 独立 MySQL 启动迁移 | 25 个迁移通过，应用成功启动 |
| 当前共享认证页、旧 LoginView、审计分支前端 build | 三者均通过类型检查和 Vite 构建 |
| 浏览器定向验证 | 每套 12 组，共 36 组通过 |
| 倒计时边界定向补测 | 每套 1 组，确认不会短暂显示 61 秒 |
| 实际注册、Mailpit 收码、旧密码登录 | 通过 |
| 错误、过期验证码 | 均被拒绝，旧密码仍有效 |

浏览器场景包括合法 8/16 位与非法 7/17 位、符号、全角、纯字母、纯数字、空格、
确认不一致、用户名误填邮箱、邮箱格式、验证码格式；非法输入不发送对应请求。
同时覆盖迟到成功/失败、改身份、取消重开、SPA 离开、双击、冻结编辑、实际 8 秒
客户端超时、冷却恢复、键盘提交和错误焦点。390×844 中文与 1366×844 英文截图
用于布局检查；重置表单允许自然纵向滚动。

浏览器 mock 报告与真实业务报告分开保存。真实链路使用正常 API 建立账号，
验证码从隔离邮件接收器读取；没有 seed/reset 后门或修改生产 Redis。
隔离栈验证码有效期缩短为 30 秒，以实际等待验证过期；生产配置不变。

## 验证中修正的测试问题

保留首次失败，不将失败证据覆盖成全绿：

1. 测试 Nginx 未透传 Host，浏览器发码被同源校验拒绝；修正测试代理后通过。
2. 重放已消费验证码时复用了被改密撤销的旧会话，先返回 403；改用全新匿名会话
   重新获取 CSRF 后确认验证码被拒绝。会话观察单独记录。
3. 只读共享依赖不允许 TypeScript/Vite 写缓存；用容器独立 tmpfs 解决，最终 build
   直接检查退出码。没有修改共享依赖或跳过类型检查。
4. 截图发现倒计时初值偶发 61 秒，统一时钟与截止时间基准后补测通过。

## 交付、部署和限制

修复同步到审计分支时保留该分支的会话快照、CSRF 和安全返回地址逻辑。
只提交代码与 PR，**未部署**。测试容器、网络和数据卷清理后，现有前后端容器 ID
及启动时间与测试前相同。原工作区未跟踪 `testkit/` 保留。

未验证真实 SMTP 投递、反馈者具体手机、Firefox/WebKit 或全部会话撤销竞争场景。
本轮通过不代表整批安全审计已验收。上线仍需单独执行；该修复无数据库迁移，
可独立回退前端，但回退会重新引入原表单提示与状态问题。
